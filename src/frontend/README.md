# AI Engineering Copilot Frontend

Next.js App Router frontend for the portfolio vertical slice.

## Local development

```bash
cd src/frontend
npm install
npm run dev
```

Set `NEXT_PUBLIC_API_BASE_URL` if the ASP.NET Core gateway is not running on
`http://localhost:5000`.

## Scripts

- `npm run dev` starts the Next.js development server.
- `npm run build` creates a production build.
- `npm run start` serves the production build.
- `npm run typecheck` runs TypeScript without emitting files.
